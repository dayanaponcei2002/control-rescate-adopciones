# Control de Rescates y Adopciones

Diseño lógico académico del sistema de control de rescates y adopciones.

## Contenido

- `docs/informe-arquitectura-rescate-adopciones.pdf`: informe técnico listo para entregar.
- `docs/informe-arquitectura-rescate-adopciones.typ`: fuente Typst del informe.
- `uml/`: fuentes Mermaid de casos de uso, clases y arquitectura.

## Gitflow

- `main`: versión estable.
- `develop`: integración.
- `feature/*`: avances de análisis, UML y patrones.
- `release/1.0.0`: preparación de entrega.
- `hotfix/*`: correcciones urgentes posteriores a publicación.
